# WebSitesTaskPaneDemo

Standalone WPF demo application for testing the website browser component.

## Purpose

Tests the WebSitesTaskPane library independently of the Word VSTO context.

## Usage

1. Open `WebSitesTaskPane.sln` in Visual Studio
2. Set `WebSitesTaskPaneDemo` as the startup project
3. Press F5 to run

Use this when developing website browsing features without needing Word open.
