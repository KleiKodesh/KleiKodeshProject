# expansion-routed.db

The search-expansion DB the app ships (FtsLib copies it next to every consumer as
`SearchExpansion/expansion-routed.db`). This is the only copy in this repo.

It is generated by the separate builder repo
[KleiKodesh/SearchExpansion](https://github.com/KleiKodesh/SearchExpansion), checked out next to
this repo at `KleiKodeshProject/SearchExpansion`. Do not edit the DB here; rebuild and ship it from
there:

```bash
cd ../SearchExpansion          # from KleiKodeshProject
python build_all.py
python build/tools/ship_to_app.py
```

then commit the updated `expansion-routed.db` here.
